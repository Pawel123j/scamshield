Suggested flow:

1. Start the app with `npm run dev` or `docker compose up --build`.
2. Use the interactive demo to create a high-risk analysis.
3. Capture desktop screenshots first.
4. Capture mobile screenshots for landing, analyzer and Senior Mode.
5. Save files in `public/screenshots/`.
