# Smoke Test Checklist

Use this lightweight checklist after major UI or analyzer changes.

- Open landing page
- Toggle Senior Mode
- Toggle Dark Mode
- Open dashboard
- Click Start Interactive Demo
- Go to analyzer
- Load fake bank example
- Run analysis
- Confirm high risk
- Confirm confidence and dominant category appear
- Review scoring breakdown
- Copy analysis summary
- Export PDF
- Open history
- Filter high risk
- Open scam database
- Search for BLIK
- Copy scam example
- Open report page
- Generate incident report
- Open privacy and security page
- Add a trusted contact
- Use trusted contact in family-help generator
- Run scenario simulator
- Confirm simulator score persists after refresh
